====================================
  碎片文字记录 (Fragments)
====================================

简介
----
  一个轻量级的碎片文字记录工具，基于 Node.js 构建。
  支持记录、编辑、排序、颜色标记和回收站功能。

功能特性
--------
  - 记录碎片文字，随时捕捉灵感
  - 支持编辑和删除操作
  - 拖拽排序，灵活组织内容
  - 颜色标记，分类管理
  - 分类页签，自定义分类管理碎片
  - 回收站功能，删除后 3 天内可恢复
  - 局域网访问，多设备同步

技术栈
------
  - 运行环境: Node.js
  - 服务器:   原生 http 模块 (无第三方依赖)
  - 数据存储: JSON 文件
  - 前端:     原生 HTML / CSS / JavaScript

快速开始
--------
  1. 确保已安装 Node.js
  2. 进入项目目录:

       cd fragments

  3. 启动服务:

       node server.js

  4. 打开浏览器访问:

       本地:     http://localhost:10086
       局域网:   http://<你的IP>:10086

项目结构
--------
  brain/
  ├── fragments/
  │   ├── server.js        # 后端服务
  │   ├── public/
  │   │   └── index.html   # 前端页面
  │   └── data/
  │       ├── fragments.json    # 碎片数据 (运行时生成)
  │       ├── categories.json   # 分类数据 (运行时生成)
  │       └── trash.json        # 回收站数据 (运行时生成)
  ├── readme.txt
  └── .gitignore

端口
----
  默认端口: 10086
  如需修改，编辑 fragments/server.js 中的 PORT 变量。

许可
----
  仅供个人使用。
